## Cập nhật

Đã cài Telegram 50 thì vào **Cài đặt → Nâng cao → Kiểm tra cập nhật**, tải xong khởi động lại ứng dụng. Gói `td-update-win-x64-*` dành cho bộ tự cập nhật, không phải file để nhấp chạy.
